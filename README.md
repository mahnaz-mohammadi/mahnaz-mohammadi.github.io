# Mahnaz Mohammadi — UX/UI Designer Portfolio

Static portfolio website for **Mahnaz Mohammadi**, UX/UI Designer.
Built with plain HTML, CSS, and JavaScript — no build step required.

# English — Deployment Instructions (GitHub Pages)

1. **Get the code** — clone or download this repository:
   ```bash
   git clone https://github.com/mahnaz-mohammadi/mahnaz-mohammadi.github.io.git
   cd mahnaz-mohammadi.github.io
   ```
   Copy all files from this package into the repo folder.

2. **Push to the `main` branch** (repo must be named `mahnaz-mohammadi.github.io`):
   ```bash
   git add .
   git commit -m "Add portfolio"
   git push origin main
   ```

3. **Enable GitHub Pages** — go to repo **Settings → Pages**, set:
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)**
   - Click **Save**.

4. Your site will be live at: **https://mahnaz-mohammadi.github.io**

> **Note:** The included `.nojekyll` file tells GitHub Pages to skip Jekyll
> processing and serve all files exactly as they are.
